# Morse code game

A simple implementation of hand tracking is used to track if the user's hand is open or closed, and these signals are then utilised as morse code. The morse and the translation are presented on the screen, letting the user see the result.

This is a very quick implementation of an idea I had, I wanted to imagine the user's hand as the beak of a goose, which would then open and close, sock puppet style. I tracked a simple eye onto the user's hand, and perhaps eventually will expand this concept into a full game, with back and forth conversation and better graphics
